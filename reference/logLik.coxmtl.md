# Log-likelihood for a `coxmtl` object

Log-likelihood for a `coxmtl` object

## Usage

``` r
# S3 method for class 'coxmtl'
logLik(object, ...)
```

## Arguments

- object:

  An object of class `coxmtl`.

- ...:

  Additional arguments (unused).

## Value

A numeric value representing the log-likelihood of the fitted `coxmtl`
object.
