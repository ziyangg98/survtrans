# Extract the coefficients from a `coxmtl` object

Extract the coefficients from a `coxmtl` object

## Usage

``` r
# S3 method for class 'coxmtl'
coef(object, ...)
```

## Arguments

- object:

  An object of class `coxmtl`.

- ...:

  Additional arguments (unused).

## Value

A named numeric vector containing the free parameters of the fitted
`coxmtl` object.
