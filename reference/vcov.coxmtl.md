# Variance-covariance matrix for a `coxmtl` object

Variance-covariance matrix for a `coxmtl` object

## Usage

``` r
# S3 method for class 'coxmtl'
vcov(object, ...)
```

## Arguments

- object:

  An object of class `coxmtl`.

- ...:

  Additional arguments (unused).

## Value

A matrix representing the variance-covariance matrix of the free
parameters.
